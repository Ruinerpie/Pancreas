# Pancreas

**A lightweight, configurable utility mod for Minecraft.**

Pancreas adds a collection of client-side tools, visual improvements, quality-of-life features, and gameplay tweaks — all managed from one clean in-game interface.

## Installation

**Requires:**
- Minecraft Java Edition 26.1.1 or newer
- Fabric Loader
- Fabric API
- Java 25 or newer

Drop the Pancreas jar into your mods folder alongside Fabric API. Launch the game, and the mod will generate its configuration on first run.

## Features

Every feature is configurable, so you can enable only what you actually want to use. Features are grouped by type — visual, utility, movement, quality of life — and each one can be toggled on or off, given its own keybind, and tuned through its own settings.

*Nothing is forced on. If you don't want a feature, you never have to see it.*

## Configuration

Pancreas is built around an in-game configuration system. 
You can manage:
- Features
- Settings
- Keybinds
- Interface options
- Visual preferences
- Per-feature options

Settings are organized per feature, and options that don't apply are hidden so the interface stays readable instead of filling up with controls you'll never touch.

## Interface

The Pancreas interface is designed to feel at home in Minecraft while still having its own identity.
It focuses on:
- Fast navigation
- Clean layouts
- Low visual clutter
- Performance
- Easy access to settings
- Custom themes and colors

The interface is dark and minimal, with a red-and-purple accent palette.

## Performance

Pancreas is built with performance in mind. Features only do work when they are needed, rendering and scanning are kept as efficient as possible, and disabled features have effectively no runtime overhead.

## Modular by design

Every feature is independent and configurable. You can turn features on or off, change their settings, assign keybinds, and keep your preferred setup between sessions.
